  • 1. From Explicit to Implicit (The Paradigm Shift)
    • NLP has moved away from manual, rigid rule-tagging toward statistical learning from contexts.
    • Explicit Knowledge
      • Traditional linguistic annotation where humans manually label structural properties (e.g., tagging "this is a NOUN").
    • Implicit Knowledge
      • Modern approach where linguistic elements are captured via statistical abstractions based entirely on the contexts where they occur.
    • The Core Assumption
      • Knowing the linguistic properties of an element means being able to use it in the right contexts, and vice versa.
    • 3 Enabling Conditions
      • Statistical representation is made possible by Huge amounts of data
      • Advanced statistical algorithms
      • High computational power.
  • 2. Representing Words
    • The Issue with Character-Based Storage
      • Traditional Approach
        • Extended ASCII stores text by assigning 8 bits to each individual character. A 4-character word takes 32 bits; a 5-character word takes 40 bits
      • The Pain Point
        • The representation length changes depending on word length
        • This variable size is highly unwanted because it complicates how computers compare different words
    • One-hot Representation (The First Fix)
      • Goal
        • To map whole words directly to distinct, fixed-sized binary patterns instead of stringing individual characters together
      • Mechanism
        • If a vocabulary has 100 words, each word gets a unique index (1 to 100). A word is represented as a 100-dimension array where all dimensions are set to 000​ except the single index slot belonging to that word, which is set to 111​.
      • Limitations
        • Highly sparse (mostly zeros) and treats every word as completely orthogonal, meaning it cannot encode any semantic similarity between related words.
    • Vector Space Models (VSM)
      • Definition
        • A continuous vector-based model compatible with machine learning and deep learning. Around 2011 (with Word2vec), the term "embedding" largely replaced "representation" in lexical semantics.
      • Mechanism
        • Placed automatically into a multi-dimensional mathematical space where word positioning maps directly to semantic attributes
      • The Foundation (The Distributional Hypothesis)
        • Proposed by Firth (1957): "A word is characterized by the company it keeps."
        • Words that appear in similar textual contexts tend to share similar meanings
        • Proximity is constructed automatically by analyzing word co-occurrences in huge corpora.
      • Training Attributes
        • Unsupervised / Self-supervised
          • The representation learning pipeline requires no manual text annotations; it supervises itself using raw text data.
        • Predictive Models
          • They are classified as predictive because they are optimized using language modeling targets, such as predicting the next word or guessing a missing word
  • 3. Constructing VSMs (Vector Space Models)
    • VSMs represent linguistic elements in a mathematical space where proximity means semantic similarity
    • There are two historical paradigms: Count-based and Predictive
      • A. Count-based Models (Traditional Paradigm)
        • Categories by Matrixes
          • These models build matrices based on raw word co-occurrence frequencies in a corpus.
            • Term-Document Matrix
              • Rows = words, Columns = documents
              • Cells store word frequencies per document
              • It is document-centric, used for macro tasks like document retrieval and classification.
            • Word-Context Matrix
              • Rows = words, Columns = contexts (neighboring words, sliding windows, or grammatical relations)
              • It is word-centric, widely used for measuring word similarity and word sense disambiguation
            • Pair-Pattern Matrix
              • Rows = word pairs (e.g., author:book), Columns = textual patterns (e.g., "X wrote Y")
              • Based on the Extended Distributional Hypothesis, it measures relational similarity (finding structural analogies between word pairs)
        • Weighting Optimization Schemes (The Filters)
          • Raw frequencies are biased by non-informative "stop words" (e.g., the, of).
          • Two mathematical filters correct this:
            • PPMI (Positive Pointwise Mutual Information)
              • Used for Word-Context matrices
              • It normalizes co-occurrence importance by dividing it by each word's individual frequency, filtering out high-frequency noise and capturing true informativeness.
            • TF-IDF (Term Frequency-Inverse Document Frequency)
              • Used for Term-Document matrices
              • TF: Local frequency in a specific document.
              • IDF: Global scarcity (log⁡(Total Docs/Docs with Term)\log (\text{Total Docs} / \text{Docs with Term})log(Total Docs/Docs with Term)​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​)
              • Rule
                • A word gets a high weight if it appears frequently in a few specific documents, but a low weight if it is spread uniformly across the entire corpus.
      • B. Predictive Models (Modern Paradigm)
        • Instead of counting frequencies, representations are learned through neural networks optimizing a language modeling objective (e.g., guessing missing words).
        • Word2vec (The Pioneer)
          • Introduced dense, fixed-sized vectors (embeddings) using two unsupervised training architectures:
            • CBOW (Continuous Bag-of-Words)
              • Predicts the target center word given its surrounding context ("Predict center from environment").
            • Skip-Gram
              • Predicts the surrounding context words given a single target center word ("Predict environment from center").
        • Resolving Out-of-Vocabulary (OOV) Words
          • When a model encounters an unseen word during inference, there are 4 solutions:
            • Default
              • Assign a random embedding.
            • Morphological Segmenter
              • Break inflected words into components (e.g., memoryless →\rightarrow→​​​​​​​​​​​ memory + less).
            • External Lexical Resources
              • Look up definitions in structured external databases like WordNet
            • Constituent Subwords (FastText)
              • Break words into character n-grams
              • The unseen word's vector is induced by averaging the embeddings of its character fragments
              • Limitation
                • Can cause semantic errors if two words share character structures but have different meanings
  • 4. Evaluation of Word Embeddings
    • Intrinsic Evaluation (Internal Metrics)
      • Evaluates the internal quality and coherence of the vector space directly, independent of downstream applications
      • It relies on semantic similarity datasets or analogy tests (e.g., King−Man+Woman=Queen\text{King} - \text{Man} + \text{Woman} = \text{Queen}King−Man+Woman=Queen​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​​).
      • 3 Critical Limitations
        • Task Mismatch
          • It ignores specific task needs;
          • POS tagging models only require coarse-grained syntax (e.g., clustering all animals), while Question Answering demands fine-grained semantics (e.g., distinguishing North from South)
        • Hubness
          • Words with similar frequencies cluster together abnormally, creating "hubs" that falsely inflate cosine similarity scores.
        • Polysemy Ignorance
          • It only tests the most frequent meaning of a word, failing to assess multi-meaning capabilities.
    • Extrinsic Evaluation (External Metrics)
      • Evaluates vectors by feeding them as input features into machine learning models for downstream NLP tasks (e.g., Sentiment Analysis, Named Entity Recognition)
      • 2 Critical Limitations
        • No "One-Size-Fits-All"
          • An embedding configuration that excels at POS tagging might fail completely at sentiment analysis
        • Confounding Variables
          • Downstream systems have many internal hyperparameters;
          • if final performance is low, it is difficult to isolate whether the root cause is the embedding or the system parameters
  • 5. Graph Embeddings
    • A graph G=(V,E)G = (V, E)G=(V,E)​​​​​​​​​​ consists of finite Nodes (VVV​) and Edges (EEE​)
    • Graph embedding maps this network data into machine-interpretable continuous spaces.
      • Node Embedding
        • Maps graph vertices into vectors while preserving structural distances.
      • Relation Embedding
        • Maps graph edges into vectors (categorized into knowledge-based and unsupervised).
    • 3 Methods for Node Embedding
      • Matrix Factorization (MF)
        • Factorizes the graph's Adjacency Matrix (which captures edge similarities) to extract node vectors.
        • Limitation
          • Highly unscalable for giant networks.
      • Random Walk
        • Performs series of truncated random paths on the graph to generate node sequences
        • These sequences act as "artificial sentences"
        • NLP predictive models (like Word2vec) are then applied to learn topological embeddings.
      • Graph Neural Networks (GNN):
        • Autoencoder-based
          • Unsupervised networks that compress graph inputs into dense hidden embeddings and reconstruct them.
        • Convolution-based (GCN)
          • Leverages local neighborhoods instead of global matrix math. It aggregates the embedding vectors of adjacent neighbors iteratively through a specified network "depth" to compute the target node's vector.
  • 6. Sense Embedding
    • The Target
      • Modeling ambiguous, polysemous lexical meanings.
    • The Core Pain Point
      • Meaning Conflation Deficiency
        • the fundamental flaw of static word embeddings where multiple meanings of a single word type are compressed into a single vector point
    • 2 Branches of Sense Modeling
      • Unsupervised Sense Embeddings
        • Induces distinct word senses purely by statistically analyzing semantic context variations inside raw text corpora
      • Knowledge-based Sense Embeddings
        • Deconflates word types into separate sense tokens by referencing external sense inventories (like WordNet)
        • It leverages two lexical resources: Textual definitions (glosses) and Semantic networks (using conceptual nodes and relational edges to resolve text ambiguity)
  • 7. Contextualized Embeddings
    • Definition
      • Dynamic word representations where a target word's embedding changes in real-time depending on the precise sentence context it appears in
      • They are assigned to Tokens (instances in context) rather than Types (dictionary entries)
    • Why they beat Word Embeddings
      • Word2vec computes static, context-free vectors that fail to adapt to shifts in syntax or semantics.
    • Why they beat Sense Embeddings
      • Sense embedding systems rely on Word Sense Disambiguation (WSD) pipelines which
        • add noise
        • suffer from limited coverage of external databases
        • and fail when context meaning does not align with rigid inventory definitions (e.g., WordNet defines tweet as a bird's chirp, missing its Twitter social-media context).
  • 8. Transformer Architecture
    • The standard neural architecture for building large language models, fully powered by Self-attention.
    • Core Components
      • Encoder stack
        • Maps a sequence of static input embeddings into a sequence of equal-length, bi-directionally contextualized output embeddings.
      • Decoder stack
        • Generates running text in an autoregressive (causal) left-to-right manner, repeatedly predicting the next token conditioned on all previously generated choices.
    • Micro-Architecture
      • Both stacks are equal sequences of layers containing two key modules followed by normalization: a Multi-head attention module and a Feedforward network.
      • The Masking Mechanism
        • The Decoder utilizes a unique Masked Multi-head attention module
        • It blinds the decoder to subsequent tokens in the target sequence during training, preventing the network from simply "copying" future tokens and forcing true causal text generation.
      • Data Flow (Inputs)
        • Text is split into tokens via tokenization
        • Initial static token vectors are added directly to Positional Encoding vectors (which supply sequential position info) before entering the attention layers
    • Mathematical Heart: The Attention Mechanism (Q, K, V)
      • Instead of squashing a whole sentence into a single fixed vector, attention creates a weighted sum of contextual tokens
      • Every token vector xjx_jxj​​​​ is projected into three distinct spaces using unique weight matrices:
        • Query (qjq_jqj​​​​)
          • The request vector representing what the current token is seeking ("What information do I need from others?").
        • Key (kjk_jkj​​​​)
          • The label vector representing what this token offers in response to queries ("What topics do I contain?").
        • Value (vjv_jvj​​​​)
          • The actual information payload retrieved once a query matches its corresponding key
        • Multi-head Attention
          • Runs this projection hhh​ times in parallel using distinct weight matrices
          • Each separate "head" pays attention from a unique perspective (e.g., one head tracks subject-verb syntax, another tracks semantic pronoun relations)
          • The resulting head vectors are concatenated and multiplied by a final weight matrix WOW^OWO​​​.
  • 9. Pre-training: Transformers as Language Models
    • Self-Supervised Learning (The Training Trick)
      • An intermediate training form where supervision comes directly from the raw data itself rather than manual labels
      • It frames learning as a prediction task by intentionally corrupting or incompleting an input sequence and training the network to reconstruct it
    • The 3 Macro-Categories of LLMs
      • Encoder-Only (e.g., BERT)
        • Acts as a denoising autoencoder
        • It is trained to reconstruct corrupted text, producing rich contextual representations
        • Optimal for representation learning and classification tasks (e.g., Sentiment Analysis, Named Entity Recognition)
      • Decoder-Only (e.g., GPT)
        • Generative, autoregressive architectures optimized for next-token prediction based exclusively on left-sided preceding context
        • This single-direction focus represents the core architecture of Generative AI and large language models (LLMs).
      • Encoder-Decoder (e.g., BART, T5)
        • Combines both stacks for sequence-to-sequence translation and structural rewriting.
    • Why Transformers beat old RNNs:
      • Parallel Computation
        • Transformers process all input tokens simultaneously (unlike sequential RNN loops), fully exploiting GPU/TPU hardware acceleration
      • No Memory Constraints
        • Self-attention tracks linguistic dependencies across long contextual distances, looking both backward and forward across sequences.
    • Deep Dive: BERT vs. GPT
      • BERT (Bidirectional Encoder Representations)
        • The first deep bidirectional language model
        • It joint-conditions representations on both left and right context across all layers using two training tasks
          • Masked Language Modeling (MLM)
            • Derived from the psychological "Cloze test," it samples 15% of input tokens for training:
              • 80% are replaced with a literal [MASK] token.
              • 10% are replaced with a completely random token (forces noise handling).
              • 10% are left entirely unchanged (prevents model over-reliance on the mask token during downstream fine-tuning).
          • Next Sentence Prediction (NSP)
            • A binary classification task where the model identifies whether a second sentence logically follows the first, capturing relationships that cross sentence boundaries.
          • Key Tokens
            • [CLS] is appended to the front of every sample to act as the global sentence representation anchor
            • [SEP] acts as the sentence boundary separator.
    • Subword Tokenization (Used by modern models like BERT)
      • Instead of encoding whole words, text is segmented into subword units.
      • 3 Big Advantages
        • Drastically downscales vocabulary size from millions of rigid words to tens of thousands of basic structural fragments
        • Eliminates Out-of-Vocabulary (OOV) errors because any unseen word can be constructed from known subword fragments
        • Allows structural and morphological knowledge sharing across similar language terms
  • 10. Knowledge Injection
    • motivation
      • Foundation LLMs possess generic linguistic knowledge but lack domain-specific expertise and suffer from hallucinations
    • Knowledge Injection augments LLMs into Knowledge-enhanced/Augmented Language Models (ALM) using two approaches
      • 1. Parametric Knowledge Injection (Static Injection)
        • Updates the model's actual internal weights and parameters via training prior to inference
        • No external data calls are made at runtime.
        • a. Fine-Tuning / Transfer Learning
          • Training a pre-trained model (e.g., BERT) on a smaller, task-specific dataset to adapt its internal representations.
        • b. RLHF (Reinforcement Learning from Human Feedback)
          • Employs a human-in-the-loop framework to train an auxiliary reward model, achieving Alignment (ensuring outputs conform to human values, safety metrics, and intent).
        • c. PEFT (Parameter-Efficient Fine-Tuning)
          • Avoids full parameter updates by freezing the foundation model and modifying only a tiny subset of parameters.
          • Additive PEFT
            • Inserts small neural modules called adapters into frozen layers.
          • Selective PEFT
            • Isolates and trains only a specified, limited percentage of the original network layers.
          • Reparameterized PEFT (e.g., LoRA)
            • Uses low-rank decomposition to train separate low-dimensional parameter matrices that represent weight updates.
        • Hybrid
          • Integrates all three methods.
        • Limitation
          • Extremely time-consuming and computationally expensive
      • 2. Non-Parametric Knowledge Injection (Dynamic Injection)
        • Integrates knowledge dynamically at inference time without changing model weights
        • It feeds domain-specific facts directly into the prompt context
        • Limitation
          • High token consumption
          • constrained by the model's maximum input context window length
        • RAG (Retrieval-Augmented Generation)
          • Combines generative LLMs with external authoritative information retrieval architectures to ground responses in factual documents.
          • The 4 Key Stages:
            • Indexing
              • Raw documents are broken up via Chunking (using fixed length with overlap, syntax-based sentence splitting, or file-format native rules), converted into embeddings, and stored inside a vector database.
            • Retrieval
              • When a user queries the system, a document retriever extracts the most contextually relevant document chunks from the database.
            • Augmentation
              • Prompt engineering combines the user's original query with the extracted document text chunks.
            • Generation
              • The LLM reads the augmented prompt and generates a response anchored in the retrieved data.
  • 11. Prompt Optimization
    • Prompting
      • Communicating instructions in natural language to a pre-trained model.
    • Prompt Design
      • Tailoring prompts to extract a desired answer for a specific task.
    • Prompt Engineering
      • Structuring inputs using explicit parameters, domain settings, or structured keywords to maximize model performance.
    • 4 Prompting Strategies
      • Zero-shot
        • Directly prompting the model without providing any functional examples
        • Pros: Highly versatile and immediate
        • Cons: Volatile accuracy, extreme dependency on perfect phrasing.
      • Few-shot
        • Providing a small set of exemplar task demonstrations to trigger In-Context Learning
        • Pros: Greatly boosts structural format accuracy and lowers ambiguity
        • Cons: Creating high-quality examples demands manual engineering effort.
      • Prompt Chaining
        • Decomposing a complex macro-problem into sequential sub-tasks handled by a chain of linked prompt executions
        • Improves controllability, audit log transparency, and debugging
      • Chain-of-Thought (CoT)
        • Introducing explicit intermediate reasoning steps (e.g., adding "Let's think step by step" in zero-shot CoT) to solve intricate mathematical and logical tasks.
          • Reasoning Language Models (RLMs) like OpenAI o1 or DeepSeek R1 natively integrate structural CoT features.
          • Tree of Thoughts (ToT)
            • A generalized expansion of CoT that creates multiple intermediate reasoning path branches in a tree framework
            • It utilizes three recursive components
              • Generation of thoughts
              • heuristic Evaluation of partial utility
              • and active branch Selection/Expansion (enabling algorithmic search and self-correction).
    • 4 Structural Elements of a Prompt
      • Instruction
        • The command stating what the model must perform (ideally placed at the very beginning).
      • Context
        • External parameters, few-shot examples, or grounding documents.
      • Input Data
        • The specific question or text payload to process.
      • Output Indicator
        • Specific formatting markers (e.g., placing "Answer:" or "Translation:" at the very end of an autoregressive prompt) to guide output generation.
    • Hyperparameters / Control Settings
      • Temperature
        • Controls selection randomness
        • Lower values generate deterministic, factual, and concise text
        • higher values elevate alternative token weights, sparking creativity and variety
      • Top P (Nucleus Sampling)
        • Restricts token selection to the top cumulative probability mass PPP​
        • Low values pick highly confident responses
        • high values expand vocabulary selection options
        • (Rule: Tune Temperature OR Top P, never both).
      • Max Length
        • Sets the absolute upper ceiling of generated tokens to prevent infinite loops.
      • Frequency Penalty
        • Penalizes the generation of a token proportionally to how many times it has already appeared in the response, diminishing raw word repetition.
      • Presence Penalty
        • Applies a flat, uniform penalty to any token that has appeared at least once, preventing the model from cycling through repetitive semantic phrases. (Rule: Tune Frequency OR Presence, never both).
  • 12. Sentence Embeddings
    • Definition
      • Compressing entire sentences or long documents into a single continuous vector space using unannotated text corpora.
    • The Compositionality Approach
      • Combines small individual token representations (words) to mathematically construct the macro meaning of longer text sequences.
    • The Flaw of Old Word Bags (Bag of Words)
      • Suffers from high dimensionality and matrix sparsity
      • Crucially, it is completely insensitive to word order
      • This makes it fundamentally unsuited for delicate linguistic comprehension tasks (like Sentiment Analysis) where syntax sequence modifies meaning (e.g., "I love coding, not reading" vs. "I love reading, not coding").
